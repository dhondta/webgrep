# Security Policy

## Supported Versions

Only the latest release of WebGrep (`webgrep-tool` on [PyPI](https://pypi.org/project/webgrep-tool/)) receives security fixes.

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

Instead, report them privately through [GitHub's private vulnerability reporting](https://github.com/dhondta/webgrep/security/advisories/new) (the repository's *Security* tab, then *Report a vulnerability*). Please include:

- the WebGrep version (`webgrep --version`) and the Python version;
- the steps to reproduce the issue, ideally with a URL or a minimal Web page that triggers it;
- the impact you expect.

You will get an answer as soon as possible. Once the issue is confirmed, a fix is released and the advisory is published.
